## 学习路线

建议按上表自上而下阅读：先熟悉张量形状、运算和基础工具，再理解线性模型与多层感知机，随后进入 CNN 和 RNN，最后联系注意力机制与计算机视觉任务。阅读每篇笔记时，可以同步查看 codes/ 中的示例，把公式、模型结构和训练过程落到可运行的实验上。

## 目录说明

- docs/：深度学习笔记正文；每个主题通常同时提供 Markdown 和 PDF 两种格式。
- codes/：与学习过程配套的代码和章节示例。
- codes/Chapter5demo：当前仓库中的章节示例代码入口。

## 笔记格式

- **Markdown**：适合在线阅读、搜索和后续修改。
- **PDF**：适合离线阅读、打印或在平板上批注。
- Markdown 与 PDF 按主题对应；如果两种格式出现差异，以最新提交的 Markdown 内容为准。
